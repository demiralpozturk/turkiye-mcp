# turkiye-mcp

An MCP (Model Context Protocol) server that gives AI assistants such as Claude Desktop, Claude Code and Cursor access to useful Turkish public data.

> **Unofficial; not affiliated with TCMB, Resmî Gazete, the Ministry of Trade or any public institution.**

Work in progress. Full documentation will follow with the first tools.

## Development

```bash
npm install
npm run build
npm test
node dist/index.js --help
```
